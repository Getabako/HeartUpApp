# AI練習メニューの使い方（スタッフ向け）

## できること

1. **テーマから作成**: 「見る・判断」「切り替え」などのテーマと、人数・時間・用具・配慮事項を入れると、W-up → Tr.1 → Tr.2 → 試合 の流れで練習メニューができます。各メニューに「やり方」「ポイント」「声かけ例」「難易度調整」が付きます。
2. **ホワイトボード写真から作成**: いつもホワイトボードに書いている練習を撮影してアップロードすると、AIが読み取って同じ形に整えます。
3. **イラスト用プロンプト**: 生成結果の下に「イラスト生成用プロンプト」が出ます。コピーしてChatGPTに貼り付けると、これまでアルバムに載せていたようなイラストが作れます。
4. **アプリ内でイラスト生成**（会社のOpenAI APIキー設定後）: 「イラストを生成」ボタンでその場で画像を作れます。1枚ごとに料金がかかるため、1日の目安枚数を表示します。
5. **保存・共有**: 保存すると練習メニュー一覧に「AI作成」カードとして残り、同じ拠点のスタッフ全員が見られます。印刷・PDF出力もできます。

## 手順

1. 「練習メニュー」タブ → 「AIで練習メニューを作成」または「ホワイトボード写真から作成」
2. 条件を入力して生成
3. 内容を確認。直したい点があれば「修正依頼」に一言入れて「修正して再生成」
4. 「保存する」
5. イラストが欲しいときは「プロンプトをコピー」→ ChatGPT に貼り付け（またはAPI設定後は「イラストを生成」）

## OpenAI APIキーの設定（管理者向け）

1. https://platform.openai.com/api-keys でキーを作成（会社アカウント推奨）
2. Vercel のプロジェクト設定 → Environment Variables に `OPENAI_API_KEY` を追加
3. 再デプロイ（Deployments → Redeploy）
4. アプリを開き直すと「イラストを生成」ボタンと、音声入力のサーバー認識が有効になります

任意で `IMAGE_DAILY_LIMIT`（1日の目安枚数、既定20）も設定できます。
